Marvellous Portal - Batch Management System
---------------------------------------------------------------------

Project Type   : Spring Boot Application  
Database       : MongoDB  
Language       : Java  
Author         : Parimal Ashok Shivale

Description:
---------------------------------------------------------------------

This project is a RESTful web application that allows you to manage
batch entries (name and fees) in a MongoDB database. It provides 
CRUD (Create, Read, Update, Delete) operations through a REST API.

Technology Stack:
---------------------------------------------------------------------

- Java 17+
- Spring Boot 3+
- Spring Data MongoDB
- Lombok
- MongoDB
- Maven or Gradle (build tool)

Project Structure:
---------------------------------------------------------------------

com.marvellous.MarvellousPortal
│
├── controller
│   └── BatchEntryController.java     --> Handles HTTP requests
│
├── entity
│   └── BatchEntry.java               --> Represents MongoDB document
│
├── repository
│   └── BatchEntryRepository.java     --> Interface for MongoDB operations
│
└── service
    └── BatchEntryService.java        --> Business logic and data access

How to Run the Application:
---------------------------------------------------------------------

1. Ensure MongoDB is installed and running on your system.

2. Clone the project or copy the source code into your IDE.

3. Configure the MongoDB connection in:
   src/main/resources/application.properties

   Example:
   spring.data.mongodb.uri=mongodb://localhost:27017/marvellous
   ------------------------------------------

4. Build and run the application using:

   Maven:
   mvn spring-boot:run
   ------------------------------------------

   OR

   Run directly from your IDE as a Spring Boot application.

API Endpoints:
---------------------------------------------------------------------

1. GET    /batches
   - Description: Get all batch entries

2. POST   /batches
   - Description: Create a new batch entry
   - Request Body: 
     {
       "name": "Java",
       "fees": 12000
     }

3. GET    /batches/id/{id}
   - Description: Get a batch by ObjectId

4. PUT    /batches/id/{id}
   - Description: Update a batch by ObjectId
   - Request Body:
     {
       "name": "Python",
       "fees": 10000
     }

5. DELETE /batches/id/{id}
   - Description: Delete a batch by ObjectId

Example JSON:
---------------------------------------------------------------------

{
  "name": "Java Full Stack",
  "fees": 15000
}

Important Notes:
---------------------------------------------------------------------

- `ObjectId` is auto-generated by MongoDB.
- Ensure Lombok plugin is enabled in your IDE.
- Proper exception handling is implemented for robustness.
- This is a modular application with clearly separated layers:
  Controller, Service, Repository, and Entity.
